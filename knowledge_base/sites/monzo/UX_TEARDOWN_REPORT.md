- **Category**: Modern Fintech & Banking (Rank #9)

## 2. The Five Planes Analysis

- **Target Persona**: Professionals, developers, or consumers seeking world-class UI ergonomics in the Modern Fintech & Banking space.
- **Conversion Goal**: Drive user acquisition and engagement through Friendly Hot-Coral / Conversational Banking aesthetics and clear value proposition.

### B. Scope Plane
- **Core Interactive Features**: Visual 'Savings Pots' with target progress rings; split-the-bill friend selector; instant spending breakdown pie.
- **Key Components**: Savings Pot Ring; Bill Splitter Drawer; Spending Category Breakdown

### C. Structure Plane (IA & IxD)
- **Navigation & Flow**: Fluid, responsive navigation hierarchy optimized for rapid scanning and minimal cognitive load.
- **Interaction Feedback**: Snappy state transitions, optimistic UI updates, and subtle micro-interactions.

### D. Skeleton Plane (Layout & Grids)
- **Container Geometry**: Centered responsive container with standard desktop max-width constraints.
- **Layout Rhythm**: Structured grid systems separating high-impact hero zones from modular feature components.

### E. Surface Plane (Sensory & Visuals)
