## 💡 Top 6 UI Design Trends to Master

1. **The "Linear Aesthetic" (Cyber-Minimalism)**:
   - Dark graphite backgrounds (`#08090a` / `#121316`)
   - 1px hairline borders with gradient angles (`border-white/10` with gradient masks)
