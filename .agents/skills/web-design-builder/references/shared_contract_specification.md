# Shared Deliverables Contract Specification

This document defines the formal shared interface between the **`web-design-learner`** skill (creator) and the **`web-design-builder`** skill (consumer).

---

## 📂 Standardized Storage Path

Every studied website has its own dedicated directory in the knowledge base:

```
d:/chris/projects/web-design-knowledge-base/
└── knowledge_base/
    └── sites/
        └── <site_slug>/
            ├── meta.json
            ├── tokens.json
            ├── extracted_variables.css
            ├── UX_TEARDOWN_REPORT.md
            └── components/
```

### Directory Slug Naming Convention
- Slugs are lowercase alphanumeric strings with hyphens: `<domain-without-tld>`
- Examples: `linear`, `resend`, `stripe`, `supabase`, `vercel`, `apple-shop`.

---

## 📄 File Contracts & Data Schemas

### 1. `meta.json` (Site Summary & Metadata)
Created by `web-design-learner` to give high-level context to `web-design-builder`.

```json
{
  "slug": "resend",
  "name": "Resend",
  "url": "https://resend.com",
  "category": "Developer Tools & Infrastructure",
  "rank": 3,
  "design_style": "Ultra-Minimalist Black & White / Code-First",
  "captured_at": "2026-09-26",
  "primary_stack": ["Next.js", "Tailwind CSS", "Framer Motion", "React Email"],
  "fonts": {
    "display": "ABC Favorit",
    "mono": "Commit Mono",
    "fallback": "sans-serif, monospace"
  },
  "deliverables": {
    "tokens": "tokens.json",
    "css_variables": "extracted_variables.css",
    "teardown": "UX_TEARDOWN_REPORT.md"
  }
}
```

---

### 2. `extracted_variables.css` (Active CSS Custom Properties)
Consolidated `:root` block generated by the Python crawler or manual token extraction. The builder agent imports this directly into project stylesheets.

```css
:root {
  --background: #000000;
  --surface-card: #0a0a0a;
  --text-primary: #ffffff;
  --text-muted: #888888;
  --border-subtle: rgba(255, 255, 255, 0.1);
  --font-mono: 'Commit Mono', Menlo, Monaco, monospace;
  --font-sans: 'ABC Favorit', 'Inter', sans-serif;
  --animate-disco-border: disco 6s linear infinite;
}
```

---

### 3. `tokens.json` (Structured Design Tokens)
Full JSON payload containing:
- `url`: Site address
- `title`: Page title
- `meta`: Viewport, description, OpenGraph metadata
- `typography.font_families`: List of identified fonts
- `tokens.css_variables`: Key-value map of every CSS variable
- `tokens.top_colors`: Frequency-ranked color palette
- `tokens.radii`: Common border-radius steps
- `tokens.shadows`: Extracted box-shadow values
- `tokens.media_breakpoints`: Responsive media query definitions

---

### 4. `UX_TEARDOWN_REPORT.md` (Architectural Blueprint)
Detailed markdown document following the Five Planes model:
- **Strategy Plane**: Target persona, conversion objective, trust factors.
- **Scope Plane**: Core features, interactive widgets, content types.
- **Structure Plane**: Navigation model, section sequence flow, state feedback.
- **Skeleton Plane**: 12-column grid geometry, container constraints (`max-w-*`), padding rhythm.
- **Surface Plane**: Typography scale, motion curves, border treatments, micro-interactions.

---

### 5. `components/` Directory (Reusable Blueprints)
Contains cleaned, framework-agnostic React/Tailwind or HTML/CSS component templates extracted from the site (e.g., `BentoCard.tsx`, `HeroSection.tsx`, `CodeRunner.tsx`).

---

## 🔄 Interaction Flow Between Skills

```
+-------------------------------------------------------------+
|                     web-design-learner                      |
|                                                             |
|  1. Crawls target site via extract_design_tokens.py         |
|  2. Analyzes Five Planes of UX                              |
|  3. Writes: meta.json, tokens.json, extracted_variables.css,|
|     UX_TEARDOWN_REPORT.md into knowledge_base/sites/<slug>/ |
+-------------------------------------------------------------+
                              │
                              ▼
           knowledge_base/sites/<site_slug>/
                              │
                              ▼
+-------------------------------------------------------------+
|                     web-design-builder                      |
|                                                             |
|  1. Discovers knowledge_base/sites/<slug>/                  |
|  2. Prioritizes local tokens over LLM generic knowledge     |
|  3. Injects extracted_variables.css into project            |
|  4. Assembles UI components adhering strictly to teardown   |
+-------------------------------------------------------------+
```
